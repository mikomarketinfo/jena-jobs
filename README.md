# Работа и Ausbildung · Jena

Личная страница на GitHub Pages, которая **каждый день** собирает вакансии в Jena и округе
(Bundesagentur für Arbeit + агрегаторы Adzuna и Jooble) и показывает их в двух колонках:
**Работа** и **Ausbildung**.

- Вкладка **«Новые»** — вакансии, найденные за последние 14 дней.
- Вкладка **«Все остальные»** — вакансии старше 14 дней, которые ещё актуальны.
- **Истекшие вакансии удаляются автоматически** (если биржа их больше не отдаёт).
- **Фильтры**: ключевые слова, исключения, радиус, Vollzeit/Teilzeit/Schicht/Praktikum,
  **Minijob** (вместе / только / без), «только с перспективой роста», сортировка.
- Галочка **«Мои стандартные фильтры»** возвращает фильтры к стандартным —
  либо **по целям** (`config/profile.json`), либо **по результату теста**.
- **Быстрые подборки** (кнопки под фильтрами): Все мои цели · Миниджоб с ростом · IT · Логистика → склад ·
  Закупки · Ещё направления. Задаются в `config/profile.json` → `presets`.
- Вкладка **«Мой план»** — направления, почему они подходят, путь к руководству и оценка влияния ИИ.
- Вкладка **«Тест профориентации»** — 10 вопросов, на выходе 2–3 направления с путём к
  небольшой руководящей должности и готовые фильтры.
- Отметки у вакансий: **★** руководство · **↗** ступенька к руководству · **→** вход в сферу с ростом.
- Клик по вакансии открывает страницу биржи, где можно откликнуться.

## Как запустить (≈10 минут)

1. На github.com нажми **New repository**, назови, например, `jena-jobs`, выбери **Public**
   (бесплатный GitHub Pages работает только для публичных репозиториев). Создай пустым.
2. **Add file → Upload files** — перетащи туда **содержимое** этой папки
   (включая скрытую папку `.github`). Если папка `.github` не загрузилась,
   создай файл через **Add file → Create new file** с именем
   `.github/workflows/update.yml` и вставь в него содержимое этого файла.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Actions** → если просят — включи workflows → **Обновить вакансии и сайт → Run workflow**.
   Через 2–5 минут сайт появится по адресу `https://<твой-логин>.github.io/jena-jobs/`.
5. Дальше обновление идёт само каждый день утром.

### Подключить больше бирж (по желанию, бесплатно)

Без ключей работает Agentur für Arbeit — это самая большая база в Германии.
Чтобы добавить агрегаторы (они собирают вакансии со StepStone, Indeed, сайтов фирм и т.д.):

| Источник | Где взять ключ | Секрет в репозитории |
|---|---|---|
| Adzuna | developer.adzuna.com → Register | `ADZUNA_APP_ID`, `ADZUNA_APP_KEY` |
| Jooble | jooble.org/api/about → запросить ключ | `JOOBLE_KEY` |

Ключи вставляются в **Settings → Secrets and variables → Actions → New repository secret**.
Напрямую StepStone/Indeed не опрашиваются: их правила запрещают автоматический сбор.

## Настройка

- `config/search.json` — **что собирать**: город, радиус (км), сколько дней вакансия считается новой,
  ключевые слова (пусто = собирать всё в радиусе — рекомендуется, фильтруется уже на странице).
- `config/profile.json` — **твои стандартные фильтры по целям** и слова, по которым вакансия
  считается руководящей / ступенькой. Его можно доработать после анализа Lebenslauf.
- Фильтры, изменённые на странице, хранятся в твоём браузере (на телефоне и компьютере — отдельно).

## Структура

```
index.html, assets/        — страница (фильтры, колонки, тест)
config/search.json         — параметры сбора
config/profile.json        — стандартные фильтры по целям
scripts/fetch_jobs.py      — сборщик (Python, без зависимостей)
data/jobs.json             — база вакансий (обновляется ботом)
.github/workflows/update.yml — ежедневный запуск + публикация сайта
lebenslauf/                — место для CV (см. предупреждение внутри!)
```

## Полезно знать

- GitHub может приостановить расписание, если в репозитории долго нет активности;
  ежедневные коммиты бота обычно этому мешают. Если обновления остановились — Actions → Enable / Run workflow.
- Первый запуск: вакансии получают дату по дате публикации, поэтому сразу разойдутся по вкладкам.

## Anschreiben с ИИ (Cloudflare Workers AI)

Код моста — в папке `worker/`, выкладка — workflow «Выложить мост ИИ».

1. Cloudflare → **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers»** → Create → скопировать токен.
2. GitHub → **Settings → Secrets and variables → Actions** → добавить:
   - `CLOUDFLARE_API_TOKEN` — токен из шага 1;
   - `BRIDGE_PASSWORD` — придуманный пароль моста.
3. **Actions → «Выложить мост ИИ» → Run workflow** (или любой коммит в `worker/`).
4. На сайте в помощнике Anschreiben нажать **⚙**, вставить адрес `https://round-forest-2940.<твой-поддомен>.workers.dev` и пароль → «Сохранить и проверить».

Модель: `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. Бесплатно — 10 000 Neurons в день (примерно 70+ писем).
В ИИ уходит только название/описание вакансии и обезличенный текст резюме; имя и контакты остаются в браузере.

# Lebenslauf

Сюда можно положить свой Lebenslauf (PDF или DOCX).

⚠️ **Важно про приватность.** Бесплатный GitHub Pages работает только для **публичных** репозиториев.
Всё, что лежит в публичном репозитории (включая эту папку), может увидеть любой человек —
адрес, телефон, дату рождения.

Варианты:

1. **Не загружать CV в этот репозиторий**, а прислать его Claude в чат — по нему будут
   доработаны стандартные фильтры (`config/profile.json`). Это самый безопасный вариант.
2. Держать CV в **отдельном приватном** репозитории.
3. Если репозиторий приватный и есть GitHub Pro — можно класть сюда.

Сам сайт эту папку **не публикует** (workflow копирует на сайт только `index.html`, `assets`, `config`, `data`),
но в публичном репозитории файл всё равно будет виден на github.com.
